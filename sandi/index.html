Hapus akun?

Data akun ini akan dihapus dari perangkat ini.

Ubah PIN

Lupa PIN?

Karena data Simpan Sandi hanya tersimpan di perangkat ini, tidak ada cara memulihkan PIN dari server. Kamu bisa menghapus data lokal untuk mengatur ulang aplikasi (semua akun tersimpan akan hilang).

Import data?

Data yang diimpor akan ditambahkan ke data yang ada.

Mulai dengan contoh data?

Kami bisa mengisi Simpan Sandi dengan beberapa contoh akun dummy agar kamu terbiasa, atau mulai dari database kosong.

Matikan PIN?

Simpan Sandi akan langsung terbuka tanpa PIN. Siapa pun yang memegang HP ini bisa melihat isinya.

Install Simpan Sandi

Browser ini belum menampilkan tombol install otomatis. Install manual cukup 3 langkah:

  1. Ketuk menu ⋮ di pojok kanan atas Chrome
  2. Pilih Instal aplikasi atau Tambahkan ke layar utama
  3. Ketuk Instal — ikon Simpan Sandi muncul di layar HP
  1. Buka halaman ini di Safari
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas)
  3. Pilih Tambah ke Layar Utama, lalu Tambah
