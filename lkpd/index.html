Tentang Aplikasi

Bantu Guru Yuk v26.5.0 adalah generator media ajar yang membantu guru membuat bahan pembelajaran secara cepat, rapi, dan siap cetak.

Dirancang khusus untuk Kurikulum Merdeka, tersedia untuk jenjang PAUD, TK, SD, SMP, dan SMA.

Fitur Free:

  • Generate prompt 2x per hari
  • Semua jenis media (LKPD, Poster, Infografis, dll)
  • Histori 5 prompt terakhir
  • Reset form

Fitur Pro:

  • Generate prompt unlimited
  • Histori 50 prompt terakhir
  • Badge Pro eksklusif
  • Prioritas fitur baru
